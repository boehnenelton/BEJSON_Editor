BEJSON Editor (104 Only)

A table view editor supporting BEJSON (Boehnen Elton JSON) 104/104a formats and MFDB (Multi File Database) manifest/entity scaffolding, with document editing, schema management, and raw-JSON inspection. This build intentionally excludes 105/105a/105db and 104db support.
